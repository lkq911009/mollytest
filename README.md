# SOLE SIGNAL — 球鞋灵感摇奖机

一个无需后端、可直接部署到 GitHub Pages 的原创球鞋主题互动摇奖机。

## 本地预览

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库。
2. 将本目录中的所有文件推送到仓库 `main` 分支。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。

站点会发布到 `https://你的用户名.github.io/仓库名/`。

## 特点

- 三列动态球鞋滚轮与可点击摇杆
- 日常、高调、未知三种互动模式
- 稀有组合、连续摇奖和结果分享机制
- 9 双原创球鞋，组合出 27 种风格信号
- 响应式布局，支持手机和电脑
- 纯 HTML、CSS、JavaScript，无依赖、无构建步骤
- 不收集或上传任何答题数据
- 图片和鞋款均为原创概念，不使用真实品牌商标
