# SOLE SIGNAL — 球鞋通关奖励舱

一个无需后端、可直接部署到 GitHub Pages 的原创球鞋知识闯关与奖励揭晓游戏。

## 本地预览

```bash
python3 -m http.server 8080
```

然后访问 `http://localhost:8080`。

## 发布到 GitHub Pages

1. 新建 GitHub 仓库。
2. 将本目录中的所有文件推送到仓库 `main` 分支。
3. 打开仓库的 **Settings → Pages**。
4. 在 **Build and deployment** 中选择 **Deploy from a branch**。
5. 分支选择 `main`，目录选择 `/ (root)`，点击 **Save**。

站点会发布到 `https://你的用户名.github.io/仓库名/`。

## 特点

- 三道球鞋知识关卡，每题即时反馈并提供知识点
- 答错不淘汰，完成挑战 100% 获得优惠券
- 根据 0–100% 正确率解锁 ¥5、¥8、¥12、¥20 四档奖励
- 答题锁定券额，机器仅负责揭晓正确率、幸运球鞋和优惠券
- 支持跳过揭晓动画；首次奖励锁定后，重玩只进入娱乐模式
- 当前为纯前端体验券；真实商用券必须接入服务端或品牌会员系统
- 响应式布局，支持手机和电脑
- 纯 HTML、CSS、JavaScript，无依赖、无构建步骤
- 不收集或上传任何答题数据
- 图片和鞋款均为原创概念，不使用真实品牌商标
